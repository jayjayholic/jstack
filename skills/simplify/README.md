# /simplify

Not a copy, just a pointer. `/simplify` is built into Claude Code by Anthropic, so you already have it: type `/simplify` after a feature works. It reviews the changed code for reuse, simplification, efficiency and the right level of abstraction, then applies the fixes. Quality only, it doesn't hunt bugs.

Why it isn't copied here: it ships inside Claude Code, which is "All rights reserved" ([LICENSE.md](https://github.com/anthropics/claude-code/blob/main/LICENSE.md)), so its text can't be redistributed. Nothing to install.
