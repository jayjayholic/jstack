# Sources: UI and visual design (house style, tokens, themes, generated artifacts)

Carried over from the research pass of 2026-10-25 (`02-research-ui-visual.md`), product-specific lines removed. Each line keeps the tag it had there: **[V]** checked against the primary page in that pass; **[K]**, **[B]**, **[C]** or **[M]** a known citation (author, year, venue) not re-opened; **[U]** unverified, treat as a hypothesis. Lines without a tag were cited with their venue and date only.

- WCAG22 - W3C, *Web Content Accessibility Guidelines 2.2*, W3C Recommendation, 5 Oct 2023. SC 1.4.3 Contrast (Minimum) 4.5:1 text; SC 1.4.11 Non-text Contrast 3:1 for UI components and graphical objects ("not rounded: 2.999:1 fails"). https://www.w3.org/TR/WCAG22/ , https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html - [verified]
- DTCG - W3C Design Tokens Community Group, *Design Tokens Format Module 2025.10*, Final CG Report, 28 Oct 2025 (token format, aliases `{group.token}`, group `$extends`; not a W3C Standard). The words "theming"/"multi-brand" were not found in the first 100k chars of the format module, so that framing is the author's, not the spec's. https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/ - [verified: title/date/aliases; theming claim unverified]
- PW-SNAP - Playwright docs, "Visual comparisons" (`toHaveScreenshot`, baselines committed, `--update-snapshots`, `threshold` default 0.2, `maxDiffPixels`, `stylePath`). https://playwright.dev/docs/test-snapshots - [verified]
- PW-EMU - Playwright docs, "Emulation": `colorScheme` 'light' / 'dark' / 'no-preference'; `page.emulateMedia({ colorScheme: 'dark' })`. https://playwright.dev/docs/emulation - [verified]
- AXE-PW - `@axe-core/playwright` README (AxeBuilder, rule `color-contrast`). https://www.npmjs.com/package/@axe-core/playwright - [verified, README only; no doc ties it to colorScheme, so run it once per emulated scheme]
- SDSV - `stylelint-declaration-strict-value` (rule `scale-unlimited/declaration-strict-value`: listed properties must use a variable/function/keyword; flags `#FFF`). https://github.com/AndyOGo/stylelint-declaration-strict-value (README lists `a { color: #FFF; }` as a warning); Mozilla's in-tree equivalent `use-design-tokens/color`: https://firefox-source-docs.mozilla.org/code-quality/lint/linters/stylelint-plugin-mozilla/rules/use-design-tokens/color.html - [verified: README; Mozilla page unverified, not re-fetched]
- MD-DENS - Material Design, "Applying density" (density levels default/comfortable/compact; dense layouts help people scan large amounts of content; compact suits data-heavy views such as tables, while focused tasks and components like date pickers need more room) and Material blog "Using Material Density on the Web", dated 16 Jan 2020 (material.io "What's new" lists it under Dec 2019). https://m2.material.io/design/layout/applying-density.html , https://m3.material.io/blog/material-density-web - [verified via search summaries only; both pages render no body text to a fetcher; M2-era]
- NIELSEN - Nielsen, J. (1994) "Enhancing the explanatory power of usability heuristics", CHI '94; NN/g "10 Usability Heuristics" (#4 Consistency and standards, #8 Aesthetic and minimalist design). https://www.nngroup.com/articles/ten-usability-heuristics/ - [known, not re-fetched; only secondary pages surfaced]
- TUFTE - Tufte, E. (1983, 2nd ed. 2001) *The Visual Display of Quantitative Information*, Graphics Press: data-ink ratio, chartjunk. - [known, not re-fetched]
- FEW - Few, S. (2006) *Information Dashboard Design*, O'Reilly: density, "single screen", avoid decoration. - [known, not re-fetched]
- FROST - Frost, B. (2016) *Atomic Design*: compose from existing atoms/molecules, pattern library as source of truth. https://atomicdesign.bradfrost.com/ - [known, not re-fetched]
- KLEIN - Klein, G. (2007) "Performing a Project Premortem", *Harvard Business Review* 85(9):18-19 (Sept 2007). - [verified citation via secondary references]
- GAWANDE - Gawande, A. (2009) *The Checklist Manifesto*, Metropolitan Books: short DO-CONFIRM checklists at pause points. - [known, not re-fetched]
- SCRUM - Schwaber & Sutherland (2020) *The Scrum Guide*: Definition of Done as a formal quality commitment for the Increment. https://scrumguides.org/ - [known, not re-fetched]

- DD - UK Design Council (launched 2004 per the Council's own Framework for Innovation page; some Council pages say the diagram was developed in 2005) "Double Diamond": discover/define before develop/deliver. https://www.designcouncil.org.uk/our-resources/the-double-diamond/ - [known, not re-fetched]
- ANTH-EVAL - Anthropic docs, "Define success criteria and build evaluations": "Be task-specific ... Don't forget to factor in edge cases"; "Automate when possible"; "choose the fastest, most reliable, most scalable method", with code-based grading listed first as "Fastest and most reliable"; "Prioritize volume over quality". Grading with a different model appears only as a code comment in the LLM-graded examples ("Generally best practice to evaluate with a different model"), not as a stated principle. https://platform.claude.com/docs/en/test-and-evaluate/develop-tests - [verified]
- ANTH-PROMPT - Anthropic docs, Claude prompting best practices ("tell Claude what to do instead of what not to do", give context/why). https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices - [known, not re-fetched this session]
- CHEN - Chen, L., Zaharia, M., Zou, J. (2023) "How is ChatGPT's behavior changing over time?", arXiv:2307.09009 (Harvard Data Science Review, 2024): same prompt, different model version, materially different behaviour and formatting. - [known, not re-fetched]
- BIANCHI - Bianchi, F. et al. (2023) "Easily Accessible Text-to-Image Generation Amplifies Demographic Stereotypes at Large Scale", FAccT '23, pp. 1493-1504, doi:10.1145/3593013.3594095: ordinary prompts (traits, occupations, objects) produce stereotyped images, with or without explicit identity language. - [verified: citation and abstract-level claim; "despite counter-prompting" detail not re-checked in full text]
- DALLEVAL - Cho, J., Zala, A., Bansal, M. (2023) "DALL-Eval: Probing the Reasoning Skills and Social Biases of Text-to-Image Generation Models", ICCV 2023, pp. 3020-3031 (per DBLP; arXiv:2202.04053): measure "the gender/skin tone distribution of generated images" across professions and attributes. The specific skin-tone detection method was not re-checked. https://github.com/j-min/DallEval - [verified: citation and abstract]
- LO - LibreOffice headless conversion (`soffice --headless --convert-to pdf`), LibreOffice help "Starting the Software With Parameters". https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html - [known, not re-fetched]
- APPROVAL - Approval / golden-master testing (Falco, ApprovalTests; Feathers, M. (2004) *Working Effectively with Legacy Code*, "characterization tests"). - [Feathers known; ApprovalTests date unverified]
- **Method:** Design-system-first composition (FROST 2016; NIELSEN #4 Consistency and standards). New screens are assembled from the project's own component kit and tokens (whatever the repo's design system or shared UI folder is), never from raw primitives; a missing piece is added to the kit first.
- **Source:** FROST 2016; NIELSEN 1994; DTCG 2025.10 (shared values live in tokens, not per-screen CSS; the theming framing is this note's inference).
- **Method:** Design tokens as the single source of truth (DTCG 2025.10), enforced by a lint rule rather than review (SDSV; Mozilla `use-design-tokens`). Lint *every* styling surface: `.css/.scss`, `.tsx/.ts` (inline `style`, Tailwind arbitrary values, SVG `fill/stroke`), `.svg`, `.json` themes, email templates, generated documents.
- **Source:** DTCG 2025.10; SDSV.
- **Source:** WCAG22 (2023); PW-EMU; AXE-PW.
- **Method:** Scope baseline + change control (PMBOK 2021); Definition of Done stated before work (SCRUM 2020). A restyle changes tokens/spacing/typography, not the DOM structure or the information shown.
- **Source:** PMBOK 7th ed. (2021; principle-based, scope baseline/change control are covered more explicitly in the 6th ed. 2017, not re-checked); Scrum Guide (2020).
- **Source:** Adzic (2011); Design Council (2005); TUFTE (1983/2001) for edge/ink economy.
- **Source:** ANTH-EVAL; Feathers (2004); LO.
- **Source:** Bianchi et al., FAccT 2023; Cho et al., ICCV 2023; Anthropic prompting guidance.
- **Method:** Golden-set regression eval run on every model/prompt change (ANTH-EVAL; CHEN 2023 shows version drift changes format behaviour). Metric = component rate: share of answers on a fixed prompt set that contain ≥1 rich component marker, plus max plain-text run length.
- **Source:** Anthropic eval docs; Chen, Zaharia, Zou (2023).
- **Method:** Density and data-ink guidance (MD-DENS: compact density suits data-heavy views such as tables; TUFTE data-ink ratio; FEW 2006 dashboard density). Width follows content: a table's width is set by its columns, not the viewport.
- **Source:** Material Design "Applying density" (2020-era); Tufte (1983); Few (2006).
- **Source:** Playwright docs; Feathers (2004).
- **Method:** Design review with before/after evidence as part of Definition of Done (SCRUM 2020); pre-mortem before large redesigns (KLEIN 2007: "it shipped and was reverted — why?"); checklist at the pause point before handoff (GAWANDE 2009). Include the *unhappy* screens (404, error, empty, blocked) in the screen inventory.
- **Source:** Klein (2007); Gawande (2009); Scrum Guide (2020).
- **Source:** General reproducibility practice; Definition of Done (Scrum Guide 2020). No single dated standard found for "open it in the reviewer's browser" — **[unverified as a named standard]**; it is a house rule.
- Token model - DTCG 2025.10 JSON + a token build (e.g. Style Dictionary)
